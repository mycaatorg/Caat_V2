# Writing desk (PROD-225)

Students should be able to browse and resume all their writing without remembering its title or which editor contains it. Add /workspace/writing, a focused overview of essay drafts and resumes, while preserving existing editors and their save queues. Existing Next.js/React/Supabase and CAAT styling; no schema, dependency, AI service or new write path.

Complete owner-filtered metadata reads for drafts, resumes and custom prompts, plus complete public prompt titles. Drafts include school name through the existing foreign-key join. No writing bodies, sections or file URLs. Any source failure shows retry, never partial counts. Account changes remount and discard old responses. Missing prompt/school context is described honestly and does not hide owned work.

Browse all writing immediately. Search titles, prompt names and school names literally; filter writing type, school (including general/untagged), current/other essay drafts; sort newest, oldest or title with stable ties. Dates are saved update times, not readiness indicators.20items per page; changes reset page and clear-filters restores defaults. Show current vs other essay drafts accurately, without treating either as submitted/complete. Each result links to its exact existing editor via PROD224's safe deep links. Empty workspace links to existing Essays and Resume builder, described as opening those tools rather than promising creation. No deletion/rename writes from overview.

Design: retain CAAT burgundy/white palette, current fonts and native controls. Desktop rows balance title+prompt context against school/status/date; phones stack these in one DOM structure with wrapping names and large links. No decorative metrics or artificial completion scores. A clear Writing desk heading and Create or edit navigation introduce the page; compact labeled filters and a quiet writing list do the work. Surface in sidebar writing group, link back from essay/resume headers. Existing search remains the all-work finder.

Validate short-cap completeness, owner predicates and explicit metadata columns, later failure, null contexts, invalid date sorting, literal search, all filter combinations, account/response races, pagination/reset; desktop and Android/iPhone exact-draft/resume navigation, no overflow, failure/retry and peer isolation. Actual Claude and independent review, hosted CI and production gates before Done. Human AT pilot remains separate.
