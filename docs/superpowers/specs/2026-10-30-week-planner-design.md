# Today planning workspace — PROD-213

Students should be able to see their next action and plan the next seven days without jumping between deadline and task pages. This is the first visible workspace upgrade following release259; it is not a whole-site redesign.

Keep Next.js/React, the existing Today loader and owner-scoped data. No dependencies, schema, notifications or new persistence. The agenda consumes comingUp deadlines and the same live personal-task state as existing editing/completion/Undo. Seven student-local dates start today; date math uses UTC purely as a date-only representation. Select a day to see every matching deadline and open dated task. Completed tasks disappear from the agenda and return after failed completion or Undo. Undated/overdue work remains reachable through the full task list and existing attention sections. Empty means no dated items for that day, not no work. Source labels distinguish personal tasks, applications, catalogue scholarships, custom scholarships and calendar events. No verified-source, reminder, progress-percentage or submission promises.

Layout: greeting and plain date; a strong maroon next-action panel with its existing explanation alongside a quiet workspace navigation column; full-width seven-day agenda; existing detailed sections below. Workspace routes are Explore scholarships (/scholarships), My shortlist (/shortlist), and Applications (/applications). Agenda task action opens the existing full to-do view at the page containing the chosen task and focuses its completion control (heading fallback when unavailable); deadline links retain original destinations. Preserve full-list URLs, pagination, editing, Undo, error handling and focus recovery.

Visual system: existing Playfair display and Source Serif body; maroon #9a1a27, deep maroon #7d141f, white #ffffff, near-white #f5f5f5, existing charcoal foreground and dark-mode tokens. Maroon next-action panel is the emphasis; agenda uses quiet borders, selected state, ordinary sentence-case copy. No decorative gradients, fake charts, new fonts or animation. Left-aligned text. On phones the date strip has its own horizontal scrolling with seven accessible buttons, never page overflow; large titles wrap. Selected date announced through pressed buttons and a polite result summary. Keyboard activation uses native buttons.

Verification: unit coverage for seven-day boundaries, date selection, mixed sources, all rows, empty days, completed/undated exclusion and live completion recovery; existing Today suite; authenticated real browser flow on desktop Chromium and phone Chromium/WebKit with screenshots, long titles, keyboard, privacy fixture, reload and navigation. Actual Claude plus fresh independent review; no Done until feature/release/main CI, deployment aliases and live checks pass. Human pilot remains separate.
